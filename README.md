# JAKS Engineering Lab Website Demo

This is a premium static website demo for **JAKS Engineering Lab**.

It is designed to work on **GitHub Pages** with no backend required.

## Files

- `index.html` — main website page
- `styles.css` — premium dark visual style, animations, responsive layout
- `script.js` — menu, scroll effects, filters, demo idea wall, WhatsApp message generator
- `assets/` — logo and placeholder project graphics

## Recommended GitHub repository name

`jaks-engineering-lab`

Your future GitHub Pages URL can look like:

`https://jakslab.github.io/jaks-engineering-lab/`

## How to upload to GitHub Pages

1. Go to GitHub.
2. Create a new repository named `jaks-engineering-lab`.
3. Upload all files from this folder.
4. Go to **Settings > Pages**.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Save.
7. Wait for GitHub to generate the live website.
